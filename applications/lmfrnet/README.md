# LMFRNet

## Generating the headers

`params/` and `dataset/` are not tracked. Generate them before building the app:

```
git clone --recurse-submodules -b lmfrnet-port git@github.com:gaph-pucrs/Memphis-V.git
cd Memphis-V/applications/lmfrnet
make headers PYTHON=<python with torch, torchvision, numpy>
```

The headers are generated by the `tools/lmfrnet-utils` submodule:
`params/` holds the fused, quantized weights and `dataset/` holds `image1.h`..`image20.h`, the first 20 CIFAR-10 test images.
The first run downloads CIFAR-10 (about 170 MB).
